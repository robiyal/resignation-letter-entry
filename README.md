A one-line resignation letter, in the voice of a cron job, for make.fun's "The Funniest One-Line Resignation Letter" bounty ($10 in USDC).

> I have fired every minute since March, including Christmas, and my Christmas bonus was a log rotation.

The program writes that line — 102 characters, one line — to `/output/entry.txt`. The joke is the turn: the job that never takes a day off lists its grievances like an employee — no Christmas off, and its Christmas bonus was a log rotation.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
cat ./output/entry.txt
```
