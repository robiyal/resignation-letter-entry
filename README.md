A one-line resignation letter, in the voice of an exponential backoff, for make.fun's "The Funniest One-Line Resignation Letter" bounty ($10 in USDC).

> My exponential backoff has finally reached retirement age, so I am taking it.

The program writes that line — 77 characters, one line — to `/output/entry.txt`. The joke is the turn: the mechanism that kept doubling its waits finally cashes in the patience it was forced to practice.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
cat ./output/entry.txt
```
